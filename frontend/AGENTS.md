# 前端界面约定

- 以 Agent 对话为主，保留独立待办页和真实可用的手动操作。
- 不添加常驻的功能说明、使用教程或后端能力边界文案，例如“支持新建与编辑”“暂不支持删除”“仅保存任务，不调用 AI”“点开查看详情”等；这些内容写在开发文档，不放在界面页脚、提示条或装饰卡里。
- 保留必要的字段标签、输入限制、空状态、数据范围标签、加载/保存反馈、异常恢复和有风险操作的确认。用“本页关联任务”等短标签表达分页范围，不用大段说明，也不暗示当前页代表全部数据。
- 延续城市、自然、人文与铁路均衡的像素风格。中文正文用易读字体；日期使用中文年月日，不用斜杠日期或浏览器原生日期/时间选择器。
- 装饰应使用本地资产、无文字、不可交互且对辅助技术隐藏；不得覆盖输入框、列表内容或按钮，不增加持续干扰输入的动画。
- 不把尚无接口的能力做成假操作；接口与业务校验不因删去说明文案而放宽。
